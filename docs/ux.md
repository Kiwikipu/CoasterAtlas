# 🗺 UX — Premier lancement

Les 2 premières minutes décident si l'application est gardée ou supprimée.

1. **Logo animé** : le globe entouré du coaster, puis « Bienvenue Atlaster 👋 ».
2. **Écran 1 : 🌍 Le monde t'attend.** Une carte pastel. « Découvre plus de XXXX parcs dans le monde. »
3. **Écran 2 : 📖 Construis ton Atlas.** Aperçu du passeport, des tampons, quelques souvenirs.
4. **Écran 3 : 🎢 Collectionne les expériences.** Défis, badges, voyages.
5. **Écran 4 : ❤️ Rejoins les Atlasters.** Seulement maintenant : créer un compte.
6. **Quel type d'Atlaster es-tu ?** (plusieurs choix) 🎢 Sensations fortes · 👨‍👩‍👧 En famille · 🏰 Univers immersifs · 🍔 Gastronomie · 📸 Photographie · 🎭 Spectacles. Sert à personnaliser l'accueil dès le premier jour.
7. Ensuite seulement : prénom, photo, connexion, puis l'accueil.

On ne vend pas une application, on vend une aventure.
